# Contributing to Autonomous Waste Sorting Delta Robot with Edge AI

Thank you for your interest in contributing to this project! We welcome contributions from developers, researchers, and hobbyists of all backgrounds.

## How to Contribute

### 1. Reporting Bugs
- If you find a bug, please check the existing issues to see if it has already been reported.
- If not, open a new issue. Include a clear title, steps to reproduce, expected behavior, actual behavior, and relevant logs or screenshots.

### 2. Suggesting Enhancements
- We are always looking to improve our robot's performance, coordinate accuracy, and computer vision models.
- Open an issue describing the proposed enhancement, why it is useful, and potential implementation details.

### 3. Code Contributions
1. Fork the repository.
2. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes and ensure the code follows PEP 8 style guidelines.
4. If you modified Python code, run tests and ensure the app starts successfully:
   ```bash
   python main.py
   ```
5. Commit your changes with a descriptive message:
   ```bash
   git commit -m "Add feature to improve coordinate transformation accuracy"
   ```
6. Push to your branch and open a Pull Request against the `main` branch.

## Coding Guidelines
- **Python**: Follow PEP 8 guidelines. Document all functions and classes with descriptive docstrings.
- **C++ (Arduino)**: Keep code modular, utilize helper functions, and avoid hardcoding motor parameters. Add comments to describe kinematics calculations.

## Code of Conduct
We support a friendly, respectful community. Please treat all contributors with respect.
